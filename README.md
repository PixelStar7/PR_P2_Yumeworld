## YumeWorld Editor
YumeWorld Editor és una eina d'escriptori desenvolupada en WPF i .NET 8 dissenyada per gestionar la base de dades del projecte YumeWorld. Permet l'edició dinàmica de personatges (Yumedants), habilitats, efectes i mapes de forma intuïtiva.
