## 📝 Descripció

**YumeWorld Editor** és una eina d'escriptori desenvolupada en **WPF** i **.NET 8** dissenyada per gestionar la base de dades del projecte YumeWorld. Permet l'edició dinàmica de:

- 🧑 Personatges (Yumedants)
- ⚡ Habilitats
- ✨ Efectes
- 🗺️ Mapes

## 🛠️ Requisits

- **.NET 8** o superior
- **Visual Studio 2022** (o un IDE compatible)
- **Windows** (per a WPF)

## 📦 Com Instal·lar

1. Clona el repositori:
```bash
git clone https://github.com/[usuari]/PR_P2_Yumeworld.git
cd PR_P2_Yumeworld
```

2. Obri el projecte a Visual Studio:
```bash
YumeWorld.sln
```

3. Restaura les dependències i compila:
```bash
dotnet restore
dotnet build
```

## 🚀 Com Usar

1. Executa l'aplicació:
```bash
dotnet run
```

2. Usa la interfície gràfica per gestionar els elements del joc

## 📂 Estructura

```
PR_P2_Yumeworld/
├── YumeWorldEditor/     # Aplicació WPF principal
├── Models/              # Models de dades
```
